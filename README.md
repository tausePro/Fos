# Felipe OS (FOS) 🚀

> Anti-procrastination web application designed for deep work and focus management

## Overview

Felipe OS is a minimalist productivity application that helps manage daily priorities and deep work blocks. Built with a "Less features, more focus" philosophy, it enforces strict limits to prevent overwhelm while maximizing productivity.

## ✨ Features

- **Daily Priority Management**: One main focus per day (max 100 characters)
- **Sacred Blocks System**: Maximum 3 deep work blocks per day (30min-2h each)
- **Category Management**: LANDINGCHAT, ESTUDIO, TAUSE, OTRO with priority scheduling
- **Time Boundary Enforcement**: 5pm hard cutoff with family time protection
- **Focus Mode**: Distraction-free work environment with timer
- **Cell Phone Mode**: Red zone calculation for minimal phone usage
- **Mobile-First Design**: Fully responsive and touch-optimized
- **Offline-First**: Complete LocalStorage persistence, no authentication required

## 🛠 Tech Stack

- **Frontend**: Nuxt 3, Vue 3, TypeScript
- **State Management**: Pinia
- **Styling**: Custom CSS with mobile-first approach
- **Build Tool**: Bun
- **Testing**: Vitest + fast-check (property-based testing)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/tausePro/Fos.git
cd Fos

# Install dependencies
bun install

# Start development server
bun run dev
```

The application will be available at `http://localhost:3002`

## 📱 Usage

1. **Set Your Daily Priority**: Define your most important task for the day
2. **Create Sacred Blocks**: Plan up to 3 focused work sessions
3. **Start Your Day**: Enter focus mode to begin productive work
4. **Track Progress**: Monitor completion and time remaining
5. **Respect Boundaries**: System enforces 5pm cutoff and family time

## 🎯 Philosophy

Felipe OS follows these core principles:

- **Constraint-Driven Productivity**: Artificial limits prevent overwhelm
- **Deep Work Focus**: Quality over quantity in task management
- **Work-Life Balance**: Hard boundaries protect personal time
- **Simplicity First**: Minimal interface reduces decision fatigue
- **Mobile-Optimized**: Accessible productivity anywhere
